# Onboarding (client)

Перше відкриття мобільного застосунку: брендований екран запуску,
вибір стартового екрана (знайомство / вхід / головний), пʼять слайдів
знайомства з продуктом і вихід у реєстрацію або вхід. Домен відповідає
за все, що користувач бачить до автентифікації, і за правило «показати
знайомство рівно один раз на пристрій».

Кожна фіча живе у власній папці зі `spec.md` (+ `plan.md`, якщо фіча
вимагатиме серверної частини).

UI реалізовано в мобільному застосунку повністю (дизайн: Figma
RF-mobile-app) — знайомство працює локально й не залежить від API.
