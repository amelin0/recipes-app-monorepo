# Progress (client)

Вкладка «Прогрес» мобільного застосунку: динаміка кожного показника, який
продукт відстежує в часі — вага, КБЖВ, вода, кроки, обʼєм талії, зріст.
Домен відповідає на питання «що змінилося», тоді як `nutrition` відповідає
на «що сьогодні».

Кожна фіча живе у власній папці зі `spec.md` (+ `plan.md`, коли бекенд
бере фічу в роботу).

UI реалізовано в застосунку на мок-даних (дизайн: Figma RF-mobile-app).
