# Subscription (client)

Усе, що відділяє безкоштовний застосунок від платного: презентація
підписки після анкети, вибір плану, погашення реферального коду,
оплата і підтвердження з датами дії — і те, що саме без підписки
замкнено та як застосунок про це каже. Домен відповідає на три
питання: «скільки це коштує», «що саме користувач уже купив» і «що
він отримує за це».

Кожна фіча живе у власній папці зі `spec.md` (+ `plan.md`, коли
зʼявиться платіжний бекенд).

UI реалізовано в мобільному застосунку повністю (дизайн: Figma
RF-mobile-app); плани, реферальні коди і стан підписки читаються з API.
Оплата — через RevenueCat
([ADR-0009](../../../adr/0009-subscriptions-via-revenuecat.md)), ще не
підключена: чекає на ключі App Store Connect і серверний контракт
(`TODO_BE.md` §10). Замки безкоштовного режиму — `free-tier`, ще не
побудовані.
